# Event Management System

A full-stack event management application built using Django, MySQL, and Stripe.

## Features
- User Registration & Login
- Event Listing
- Event Registration
- Stripe Payment Integration
- Google OAuth Authentication
- Admin Dashboard

## Technologies Used
- Python
- Django
- MySQL
- HTML
- CSS
- JavaScript
- Stripe API

## Project Setup

1. Clone the repository
2. Install dependencies
3. Configure environment variables
4. Run migrations
5. Start the Django server
